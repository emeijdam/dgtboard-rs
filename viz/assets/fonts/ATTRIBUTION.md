# HUD font

`DejaVuSans-subset.ttf` is DejaVu Sans 2.35 (the DejaVu fonts project,
derived from Bitstream Vera; see `LICENSE_DEJAVU`), subset with
`pyftsubset` to Latin, punctuation, arrows, technical, geometric and
miscellaneous symbols, and dingbats — so the HUD can show `♔ ♚ ← → — · ✓ ⚠`,
which Bevy's built-in font lacks. No glyphs were altered.
